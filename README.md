# UFO Sightings Exploratory Data Analysis

## Educational Data Science Course Project

Created in **2024** as part of my Data Science learning journey, this repository presents an educational learning project. It is a documentation-first portfolio version of an earlier notebook exercise.

The project explored a public-style UFO sightings dataset through data cleaning, descriptive analysis, visualisation, and basic text exploration of written reports.

## What was explored

- Cleaning dates, durations, locations, and reported shapes
- Descriptive visualisation by time, country, reported shape, and duration
- Simple text exploration of sighting comments
- An experimental latitude/longitude regression attempt

## Important status

The original learning notebook and its outputs are intentionally not published here. Its data source, licence, environment, and results require a clean reproducibility review before executable code can be published responsibly.

This repository does **not** claim to verify UFO sightings, predict real-world events, or establish psychological findings from written comments.
